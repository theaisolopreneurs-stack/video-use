# LUTs (colour looks)

Drop `.cube` LUT files here (or in a project's folder) and they appear as looks in the
Review Studio, or set `"grade": "lut:<file>.cube"` in plan.json.

`warm_soft.cube` is generated by this project (gentle warmth + soft contrast), free to use.

Free LUT sources: many camera makers publish free conversion LUTs, and sites like
FreshLUTs list free creative LUTs — check each licence before using.
Tip: LUTs built for log footage (S-Log, V-Log) look wrong on normal phone video.
